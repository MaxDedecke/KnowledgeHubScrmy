# Anforderungen (freigegeben)

## Datei hochladen

- Priorität: Hoch

Die Benutzer können über die Oberfläche eine Datei auswählen und ins System hochladen. Das System speichert die Datei und macht sie für weitere Funktionen wie Kommentierung und Anzeige verfügbar.

## Akzeptanzkriterien
- Der Benutzer kann über einen Upload-Button eine Datei von seinem Gerät auswählen.
- Nach dem Auslösen des Uploads ist die Datei im System gespeichert.
- Die hochgeladene Datei ist zu einem späteren Zeitpunkt weiterhin im System auffindbar.

## Kommentar zu einer Datei erstellen

- Priorität: Hoch

Die Benutzer können zu einer hochgeladenen Datei einen Kommentar verfassen und speichern. Dadurch lassen sich nicht digitalisierte Inhalte an die relevante Datei anknüpfen.

## Akzeptanzkriterien
- Der Benutzer kann eine gespeicherte Datei auswählen und einen Text als Kommentar eingeben.
- Der Kommentar wird nach dem Speichern dauerhaft mit der ausgewählten Datei verknüpft.
- Ein gespeicherter Kommentar bleibt bei späterem Öffnen der Datei erhalten.

## Kommentare zu einer Datei anzeigen

- Priorität: Hoch

Das System listet zu jeder hochgeladenen Datei die vorhandenen Kommentare auf, sodass die verknüpften nicht digitalisierten Inhalte für die Nutzer sichtbar werden.

## Akzeptanzkriterien
- Beim Öffnen einer Datei werden alle zu dieser Datei gespeicherten Kommentare angezeigt.
- Neu hinzugefügte Kommentare erscheinen unmittelbar in der Kommentarliste der Datei.
- Die Kommentare sind inhaltlich lesbar und klar der jeweiligen Datei zugeordnet.
